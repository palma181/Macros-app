# Mis macros (app instalable)
1. Sube TODOS estos archivos a un repositorio de GitHub (en la raíz).
2. Settings > Pages > Source: "Deploy from a branch" > main / (root) > Save.
3. Abre https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/ en Chrome del celular > menú ⋮ > "Instalar app".
4. Opcional, para un APK: pega esa URL en pwabuilder.com > Package for stores > Android.
5. En la pestaña IA configura tu proveedor y clave de API.
